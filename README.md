# KPI 실습앱

## 파일 역할

- `index.html`: 기존 원본 화면
- `실습앱/index.html`: 분리된 실습 화면
- `실습앱/style.css`: 화면 스타일
- `실습앱/app.js`: 화면 렌더링, 필터, 입력 동작
- `실습앱/core.js`: 샘플 데이터, 계산, 값 검사
- `실습앱/data/kpi.json`, `kpi.csv`: 가져오기·원본 비교용 사본
- `prd.md`: 현재 확인한 요구사항과 다음 단계 제안
- `schema.sql`: 실제 실행하지 않은 DB 설계안
- `config.example.js`, `config.js`: 아직 읽지 않는 공개 설정 자리표시자
- `검증체크리스트.md`: 샘플·화면·DB 연결 후 체크 항목

## 실행

브라우저에서 `실습앱/index.html`을 직접 열 수 있다. 직접 파일을 여는 경우에도 앱은 `core.js`의 샘플을 사용하므로 데이터 fetch에 의존하지 않는다.

## 샘플과 DB의 차이

현재 샘플은 메모리에만 존재하며 새로고침하면 초기화된다. JSON·CSV는 앱이 자동으로 읽거나 저장하는 DB가 아니라 가져오기 및 원본 비교용 사본이다. 실제 DB 연결은 아직 하지 않았다.

## GitHub에 올릴 파일

소스와 문서인 `index.html`, `실습앱/`, `prd.md`, `schema.sql`, `README.md`, `검증체크리스트.md`, `config.example.js`를 올릴 수 있다. 실제 비밀값이 들어간 설정은 올리지 않는다. 현재 `config.js`는 빈 자리표시자만 있으므로 연결 시 비밀값을 입력하지 않은 상태로 관리한다.

## 범위 밖
